# Matriz de referências — evolução 0.3

Inspeção em **22/10/2026**, sobre Zetta `4f444c289d9eeb584be66c9949ef264739b7686c` (o SHA exato da base está na [auditoria](evolution-audit.md)). As referências abaixo foram examinadas por documentação, manifests, licenças e caminhos de código. A triagem não instalou nem executou os 14 aplicativos. As provas executadas no Zetta estão no [registro de validação](validation-0.3.md); README e código existente não significam uma integração validada.

Decisão central: conservar o contrato de slides/SVG e o ECharts já integrado; acrescentar apenas **svg2pdf.js 2.8.1** como pacote de runtime nesta etapa. Os quatro blocos de diagrama e os controles de recorte cabem nas estruturas atuais. Fontes Liberation 2.1.5 são recursos estáticos licenciados, sem serviço de fontes ou modelo.

## 5. Fontes incorporáveis

[Liberation Fonts](https://github.com/liberationfonts/liberation-fonts/tree/49e1358e4017577429c9f8c39a3e6e879093264e), release oficial2.1.5, OFL1.1. Foram escolhidos TTF estáticos de Liberation Sans e Serif, Regular/Bold. SHA256 do arquivo oficial: `7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0`. Os hashes dos quatro TTF constam no [dossiê de renderização](research/rendering.md). O código fonte referenciado e o artefato de release foram inspecionados separadamente.

Os TTF foram lidos com FontTools: permissões de embedding `fsType=0` e cobertura dos caracteres da prova em português. Isso não significa suporte a todo Unicode. Fontes do sistema dos decks legados são substituídas explicitamente no PDF pesquisável, sem alterar o documento. Não redistribuímos Arial ou Georgia.
